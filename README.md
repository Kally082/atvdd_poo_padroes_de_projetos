# Padrões de Projeto em Java

Este repositório reúne a resolução da atividade proposta pelo professor Kenji Kamei na disciplina de Programação Orientada a Objetos. Cada exercício parte de um código com problemas de projeto e apresenta a versão refatorada com um padrão de projeto.

## Padrões aplicados

| Padrão | Problema resolvido |
|---|---|
| Strategy | Cadeia de `if/else` para escolher o cálculo de frete |
| Singleton | Múltiplas instâncias de uma classe de configuração pesada |
| Factory Method | Regra de negócio acoplada à criação de objetos concretos |
| Abstract Factory | Mistura acidental de componentes de temas diferentes |
| Adapter | Biblioteca legada incompatível com a interface do sistema |
| Observer | Classe acoplada diretamente aos serviços que reagem a um evento |
| Decorator | Combinação de funcionalidades sem criar uma subclasse para cada uma |

## Organização

Cada padrão fica em sua própria pasta, e cada classe refatorada traz no topo um comentário explicando o problema resolvido.
